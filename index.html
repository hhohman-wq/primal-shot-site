Support

Need help? Email hhohman13@gmail.com and include your device model. We usually reply within a few days.

My purchase didn't show up

Open the Shop or Settings and tap Restore purchases. Make sure you're signed in with the same Apple ID you bought with. Gold packs are delivered once; if one is missing after a purchase, restart the game while online.

How do I cancel the Hunter's Pass?

On iPhone: Settings → your name → Subscriptions → Primal Shot → Cancel Subscription. The Pass stays active until the end of the paid month.

Can I move my progress to a new phone?

Settings → Copy save code on your old phone, then Settings → Load save code on the new one. Purchases come back with Restore purchases.

The game feels slow

Settings → Graphics → Low makes it run smoother on older phones.
